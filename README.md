# 📊 Sales Performance Dashboard – Excel

## Project Overview
An interactive Sales Performance Dashboard created using Microsoft Excel to analyze sales, profit, product performance, and regional trends.

## Tools & Skills
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- KPI Cards
- Slicers
- Excel Formulas

## Dataset Details
- 500 Sales Records
- 10 Products
- 3 Categories
- 4 Regions

## Dashboard KPIs
- Total Sales: ₹2,81,51,950
- Total Profit: ₹71,60,040
- Total Quantity: 2,286
- Total Orders: 500

## Dashboard Visualizations
1. Sales by Region
2. Product-wise Sales
3. Monthly Sales
4. Profit by Category

## Interactive Features
- Region Slicer
- Category Slicer
- Dynamic Dashboard Filtering

## Key Insights
- West region achieved the highest sales.
- Laptop was the highest-selling product.
- August recorded the highest monthly sales.
- Electronics generated the highest category-wise profit.

## Project Objective
To transform raw sales data into meaningful business insights using Excel dashboard techniques.
