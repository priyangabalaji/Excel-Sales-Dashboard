# Excel Sales Performance Dashboard

## Project Overview
This project focuses on analyzing sales data and creating an interactive Sales Performance Dashboard using Microsoft Excel. The dashboard helps understand business performance through KPIs, Pivot Tables, Pivot Charts, and Interactive Slicers.

## Dataset Information
- Total Records: 500
- Products: 10
- Categories: 3
- Regions: 4

## Key Performance Indicators (KPIs)
- Total Sales: ₹2,81,51,950
- Total Profit: ₹71,60,040
- Total Quantity Sold: 2,286
- Total Orders: 500

## Dashboard Features
- Sales Analysis by Region
- Monthly Sales Trend
- Product-wise Sales Analysis
- Profit Analysis by Category
- Interactive Region Slicer
- Interactive Category Slicer
- Dynamic Pivot Charts and KPI Cards

## Key Business Insights
- West region recorded the highest sales.
- North region recorded the lowest sales.
- Laptop was the highest-selling product by sales value.
- Mouse recorded the lowest sales value.
- August recorded the highest monthly sales.
- Electronics generated the highest profit among categories.

Developed an interactive Excel dashboard to analyze sales performance, identify business trends, compare regional sales, and generate meaningful business insights.
